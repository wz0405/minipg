거래 시딩

정산 파이프라인에 태울 대량 거래를 만듭니다. 같은 기간 재실행 시 기존 시딩을 지우고 다시 생성합니다(멱등).

배치 수동 실행

운영 스케줄 — 23:30 자동취소 동기화 · 04:00 일정산 · 06:00 지급 처리 · 00:10 가상계좌 만료회수. 재실행은 멱등입니다.

일정산 · 월 마진

가맹점 × 결제수단 그레인. 마진(판가-원가)은 PG 내부 지표라 이 화면에만 노출됩니다.

거래 원장

승인·취소 전 행이 INSERT-only로 남습니다. 취소는 음수 금액의 별도 행입니다.

가상계좌

제휴사 벌크 계좌풀에서 채번하고, 입금통보 웹훅이 도착하면 원장에 적재됩니다. 만료 채번은 배치가 풀로 회수합니다.

오프라인 단말 (VAN 통보)

단말기에서 이미 승인된 거래가 고정길이 바이너리 전문(80B, EUC-KR)으로 통보됩니다. 가맹점은 전문에 없어 단말번호로 역조회하며, 재전송 통보는 멱등 처리됩니다. 아래 버튼이 단말기 역할을 시뮬레이션합니다.

정기결제 (빌키)

발급은 0원 인증입니다 — 카드 유효성만 확인하고 빌키를 받으며 청구가 없습니다. 실제 청구는 [회차승인]을 눌렀을 때만 발생합니다. 카드 원본은 저장하지 않습니다.

선불 (머니·포인트)

잔액 UPDATE는 조건부(잔액부족 원자 차단), 모든 변동은 이력으로 남습니다. 충전 후 결제 데모에서 사용해 보세요.
